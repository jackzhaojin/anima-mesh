# drafts/defects/ — fallback defect drafts

Empty in the healthy state — and that is the point.

When a run reports an ENGINE defect, the leak-clean path files it directly
as a public issue on the engine repo (decision
`bundle/decisions/2026-06-08-defects-file-as-issues.md`); no draft is
kept. A draft lands here only when filing can't happen: the identity-leak
guard tripped, the API failed, or no token is configured. The founder
promotes or discards fallback drafts by hand.
