# Event: librarian first pass

The librarian's first weekly run cataloged the founder's document store
into `cabinet/` — one concept per key document, originals staying outside
the repo.

One correction, and it set the norm:
[facts/corporate-identity.md](../facts/corporate-identity.md) carried an
authorized-share count of 10,000,000 from a working session's recall. The
certificate of incorporation says **8,000,000**. The fact was corrected,
sourced to the cabinet concept, and marked `verified`. Recall is not a
source; the bundle is.
