# Bundle log

Append-only. New entries go at the end; history is never rewritten —
corrections are new entries. This file is the story of the company's
operating system, told forward.

## 2026-03-10 — Program start

Repos created: this private instance and the public engine it pins
(`animamesh.config.json` → `engine.ref`). Bundle scaffolded; constitution
adopted; agent roster instantiated — all five agents at L1 (report-only)
per the autonomy ladder. The two-repo rule is the founding constraint:
everything naming Copperline or its people lives here; everything generic
lives in the engine and must never reference this firm.

## 2026-03-18 — Librarian first pass

The filing cabinet cataloged: one concept per key document under
`cabinet/`, originals staying in cloud storage. First correction landed the
way corrections are supposed to: `facts/corporate-identity.md` had the
authorized-share count from a session's recall (10,000,000); the
certificate says **8,000,000**. The fact now cites the cabinet concept and
carries `status: verified`. Recall is not a source.

## 2026-04-02 — Cloud tier becomes the default runtime

The daily heartbeat moved from the founder's laptop to a scheduled worker
running against the hosted copy of this repo (decision
`decisions/2026-04-02-runtime-posture-cloud-default.md`). Nothing about the
agents changed — the bundle is the only state, so the same brain runs
wherever the repo is. The laptop stays as the interim net.

## 2026-05-11 — Hub promoted to L3; first wake consumed

Mira promoted L1 → L3 with a whitelist of exactly `schedule-update`
(frontmatter edit in `agents/chief-of-staff.md`, per the ladder). Same
week she used it: her brief ended with a `schedule-request` block waking
compliance-ops ahead of its cadence for a filing-deadline check. The
harness applied it through the whitelist gate, ledgered it, and the wake
was consumed at the next beat. Propose → dispose, working as designed.

## 2026-06-08 — Defect loop live; capability truth in every prompt

Two trust expansions in one entry. Mira's whitelist gained `draft-write`
(nag prep packs under `drafts/nag-prep/`) and `defect-report` — when the
ENGINE misbehaves, her run ends with a defect block and the harness files
a leak-scanned public issue on the engine repo; a draft is kept only when
filing can't happen. And every run's prompt now states what its runtime
actually grants (file reads, web search budget) after the job description
— an agent never again reports a missing tool as a broken one.
